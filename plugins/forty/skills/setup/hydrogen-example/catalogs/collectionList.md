# collectionList

A row of two to four collection tiles — image and name — each linking to that collection's page in the store.

## When to Use

The visitor is orienting rather than choosing: "what do you sell", "where do I start", or a broad question where pointing at the right categories beats listing products.

## Don't Use When

The visitor asked for specific products — use `productGrid`. Or only one collection is relevant — use `collectionHero`.
