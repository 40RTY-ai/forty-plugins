# productGrid

A titled grid of products, each drawn as this store's product card: image, name, price, a sale or new label, and an add-to-cart button.

## When to Use

The visitor wants to see, browse or compare specific products — "show me bralettes", "something seamless under a white tee", "what's on sale". The default way to answer any product question.

## Don't Use When

The visitor is still orienting between categories rather than choosing items — use `collectionList`. Or the answer is a single category worth a full-width spotlight — use `collectionHero`.
